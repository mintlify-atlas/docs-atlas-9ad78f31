zEnv is a zero-knowledge secret manager built for teams who need to store, share, and inject secrets securely. Unlike traditional secret managers, all encryption and decryption happens on your machine — the zEnv server is a ciphertext warehouse that mathematically cannot read your data.

## What makes zEnv different

zEnv's core property: **the server never sees your plaintext secrets**. Encryption and decryption happen entirely on your device using the Amnesia cryptographic engine. The server stores only ciphertext it cannot decrypt.

<CardGroup cols={3}>
  <Card title="Client-side crypto" icon="lock">
    AES-256-GCM encryption with Argon2id key derivation — all computed locally before any data leaves your machine.
  </Card>
  <Card title="Zero-trust server" icon="server">
    The API stores encrypted blobs only. Even with full database access, secrets remain protected.
  </Card>
  <Card title="Typed secrets" icon="check-double">
    The TypeScript SDK validates decrypted values against your Zod, Valibot, or ArkType schema.
  </Card>

## Getting started

<Steps>
  <Step title="Install the CLI or SDK">
    Build the CLI from source or install the TypeScript SDK via pnpm.

    ```bash
    # CLI (from source)
    make build
    ./bin/zenv --help

    # TypeScript SDK
    pnpm add @zenv/sdk
    ```
  </Step>
  <Step title="Set your credentials">
    Configure your service token and project key as environment variables.

    ```bash
    export ZENV_TOKEN=ze_...
    export ZENV_PROJECT_KEY=...
    export ZENV_PROJECT=<project-id>
    export ZENV_ENV=production
    ```
  </Step>
  <Step title="Store your first secret">
    Encrypt a secret client-side and store it in the vault.

    ```bash
    zenv secrets set DATABASE_URL "postgres://prod:secret@db.internal/myapp"
    ```
  </Step>
  <Step title="Fetch it in your application">
    Load and validate secrets with the TypeScript SDK.

    ```typescript
    import { zenv } from "@zenv/sdk";
    import { z } from "zod";

    const vault = zenv({
      token: process.env.ZENV_TOKEN!,
      projectKey: process.env.ZENV_PROJECT_KEY!,
      projectId: process.env.ZENV_PROJECT_ID!,
      schema: z.object({
        DATABASE_URL: z.string().url(),
        STRIPE_API_KEY: z.string().min(1),
      }),
    });

    const secrets = await vault.load();
    // secrets.DATABASE_URL → validated string
    ```
  </Step>
</Steps>
